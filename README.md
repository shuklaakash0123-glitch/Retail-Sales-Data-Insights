# Retail-Sales-Data-Insights
Retail sales analysis using Python, Pandas, SQL and Power BI.
## Project Overview

This project analyzes retail sales data to identify sales trends, top-performing products, categories, regions and customer behavior.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Excel

## Key Insights

- Total Revenue: ₹210,400
- Total Orders: 10
- Average Order Value: ₹21,040
- Best Performing Category: Electronics
- Best Performing Region: North
- Best Sales Month: March
